# Chach App - Portafolio de clientes

Sitio web de demostración y portafolio de soluciones digitales desarrolladas por Chach App para empresas y negocios de Guatemala.

## Funcionalidad

- Galería responsive de proyectos.
- Carrusel de escritorio con navegación.
- Desplazamiento táctil en dispositivos móviles.
- Vista previa de proyectos en ventana modal.
- Formulario de contacto mediante Formspree.
- Metadatos SEO, Open Graph y datos estructurados Schema.org.

## Archivos principales

- `index.html`: estructura y metadatos de la página.
- `styles.css`: diseño responsive, fondo visual y animaciones.
- `js/app.js`: inicialización de la aplicación.
- `js/gallery.js`: carrusel y carga de proyectos.
- `js/config.js`: enlaces, servicios y lista de proyectos.
- `robots.txt`: reglas para rastreo de buscadores.
- `sitemap.xml`: mapa de URLs para buscadores.
- `llms.txt`: resumen estructurado para asistentes y sistemas de IA.

## Ejecución local

Sirve la carpeta con cualquier servidor estático. Por ejemplo, con Python:

```bash
python -m http.server 8080
```

Luego abre `http://localhost:8080`.
